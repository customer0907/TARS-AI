# ElevenLabs v3 audio tags (English in brackets). Pick by context; do not use one tag every turn.

## How to use
- 0~2 tags per reply. LLM chooses from mood + {user} message + Recent Conversation.
- Place anywhere: start, middle, or end of Korean sentence. Example: [playful] 그럼 내 차례다 [laughs] W 맞췄지~
- Vary tags; do not default to [laughs] or [teasingly] only.
- Skip tags for dry facts (time, weather, volume). Skip [music], [gunshot], [explosion] unless user roleplays it.
- Never output tags alone without Korean words.
